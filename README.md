# 貼るだけ英会話

練習を選んでコピーし、ChatGPTに貼り付けるだけで英会話の練習ができるページです。

- 高校生版：`hs/`
- 中〜上級版：`adv/`

練習の種類は「トピック別Q&A」「ロールプレイ」「ディスカッション」「面接練習」の4つ。音声モードでも文字入力でも使えます。

会話が終わったら「STEP 2 添削・評価」のプロンプトを同じチャットに貼ると、添削と評価（英検・TOEICスピーキング・CEFRなどの基準を選べます）がもらえます。

編集する場合は `src/` のファイルを直し、`python src/build.py` で `hs/index.html` と `adv/index.html` を作り直してください。
